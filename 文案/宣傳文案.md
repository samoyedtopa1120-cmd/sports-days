# 宣傳文案 (U・ω・U)

主題：守護薩摩耶的健康。
每月挑需要的段落，改掉 {{ }} 裡的日期與數字就能用。語氣保持「觀眾出錢，狗狗出力」的自嘲與互動感。

---

## 一、核心口號（放標題、封面、縮圖）

- 你投罐罐，我做深蹲。守護薩摩耶的健康，就靠你了。
- 一罐一蹲，餓犬不胖。
- 這不是賭博，是健康管理。(｀・ω・´)
- 每月一次，全民監督薩摩耶運動。
- 想看狗運動？投罐罐就對了。想放過狗？那要看運氣。

## 四、規則文件引言（放規則最上方）

```
為什麼要辦運動會？
因為薩摩耶會胖，而且不會自己動。
每個月一次，大家用罐罐換我的深蹲與健身環時間，
用一番賞決定我要不要做大冒險，
用對戰決定誰的尊嚴比較值錢。
這是一場守護薩摩耶健康的集體行動。(・ω・)ノ
```
