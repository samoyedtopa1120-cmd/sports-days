# 多帕運動會 (U・ω・U)

守護薩摩耶的健康，從每月一次的運動會開始。
這個資料夾存放每個月運動會的規則、圖片、範本與宣傳文案，方便每月更新、對照與回顧。

---

## 資料夾結構

```
運動會/
├── README.md                 ← 你現在看的這份
├── 2026/
│   └── 11月/
│       ├── 規則.md           ← 當月正式規則（給觀眾看的版本）
│       └── 圖片/             ← 當月轉盤、一番賞、扭蛋機的設定截圖
├── 範本/
│   └── 月度規則範本.md       ← 每月複製這份來改
├── 文案/
│   └── 宣傳文案.md           ← 開台公告、DC 公告、規則引言、投稿號召
└── 共用/
    ├── 周邊清單.md           ← 跨月通用的周邊品項
    └── 周邊圖片/             ← 周邊照片
```

### 命名規則
- 年份一層、月份一層：`2026/11月/`、`2026/12月/`、`2027/1月/`
- 每月固定有 `規則.md` 和 `圖片/`，檔名不要改，方便跨月比對
- 圖片用內容命名：`一般轉盤設定.png`、`一番賞設定.png`、`扭蛋機機率.png`
- 只在該月出現的特別企劃，放在該月資料夾下，例如 `2026/12月/聖誕特別企劃.md`

---

## 每月更新流程

1. 複製 `範本/月度規則範本.md` 到 `YYYY/M月/規則.md`
2. 依下方「每月必改清單」把 `{{ }}` 全部填掉
3. 把當月轉盤、一番賞、扭蛋機的設定截圖放進 `YYYY/M月/圖片/`
4. 用截圖核對規則文字裡的機率，兩邊要一致
5. 從 `文案/宣傳文案.md` 挑一份改日期，貼到 DC 與開台公告
6. 月底把「目前進度」（集點卡、進度條）更新成最終結果，方便回顧

### 每月必改清單
- [ ] 月份與標題
- [ ] 投罐罐時間（起迄日期與星期）
- [ ] 本月新制或特別企劃
- [ ] 大冒險分級與取得方式
- [ ] 一番賞內容與機率（總枚數）
- [ ] 一般轉盤獎項與機率（相加要是 100%）
- [ ] 扭蛋機內容與權重
- [ ] 集點卡目前點數、進度條門檻
- [ ] 周邊品項（若有新增或下架）
- [ ] 對戰價格與倍率（通常不變，仍要確認）

### 檢查重點
- 文字版機率與截圖是否一致
- 大冒險等級編號是否前後一致（分級表、一番賞、一般轉盤三處）
- 備註裡有沒有上個月殘留的月份
- 周邊編號是否連號

## 文件風格
- 給觀眾看的規則以「先看重點、再看細節」排列：活動時間 → 價目表 → 各玩法
- 機率一律用表格，由高到低排序
- 不用 emoji，章節標題後面放日式顏文字，例如 `(・ω・)ノ`、`ヽ(´ー`)ノ`
- 數字用半形，金額加千分位（3,000）
